# Jeu survie cubes – prototype

Petit jeu de survie / exploration en vue isométrique, dans le navigateur.

## Jouer

En ligne : https://TON-PSEUDO.github.io/NOM-DU-DEPOT/

En local : ouvrir `index.html` dans un navigateur.

## Commandes

| Touche | Action |
|---|---|
| Z Q S D / flèches | Se déplacer |
| Maj | Courir |
| A | Ramasser une pierre / gratter un arbre (avec une pierre aiguisée en main) |
| E | Ouvrir / fermer l'inventaire |
| Molette | Zoomer / dézoomer |

## Fabrication

Dans l'inventaire : une pierre en main + une pierre dans la zone **Sol** → la frappe se lance seule (3 s).
Pierre → abîmée → très abîmée → poussière. La pierre tenue devient aiguisée.
